## 🗂️ پروژه‌های برجسته (تحلیل فنی)

### ۱. Easy_Learn | سامانه جامع آموزش آنلاین (LMS)

[![Readme](https://img.shields.io/badge/مشاهده-پروژه-blue?style=for-the-badge&logo=github)](https://github.com/abolfazlmo006/Easy_Learn)

**معماری:** سه لایه (Data, WebApi, MVC UI)  
**خلاصه:** یک سامانه کامل مدیریت آموزش (LMS) که از ثبت‌نام دانشجو تا فروش دوره را مدیریت می‌کند.

#### تحلیل عمیق معماری:
- **لایه Data (EF Core):**
  - شامل **۱۴ موجودیت** پیچیده مانند `CourseEntity`، `UserEntity`، `OrderEntity`، `AnswerQuestionEntity` و ...
  - طراحی پیشرفته روابط چند به چند (مثلاً `CourseEntityUserEntity` برای ثبت‌نام دروس).
- **لایه WebApi:**
  - **۱۳ کنترلر API** برای تمامی موجودیت‌ها.
  - پیاده‌سازی **احراز هویت JWT** و **ASP.NET Core Identity**.
  - استفاده از **NSwag** برای تولید OpenAPI Specification بومی و ساخت کلاینت C# به صورت خودکار.
  - استفاده از الگوی **DTO** و **AutoMapper** برای جداسازی Entity از Model.
- **لایه UI:**
  - پروژه MVC با جداسازی کامل بخش **Admin Area**.
  - قابلیت **Real-Time Notification** با استفاده از **SignalR**.
- **Persian Translation Layer:** ترجمه سفارشی خطاهای Identity اعم از خطاهای ثبت‌نام، ورود و قفل شدن حساب کاربری.

**تکنولوژی‌های کلیدی استفاده شده:**
`ASP.NET Core 7` `EF Core` `SQL Server` `Swagger` `NSwag` `AutoMapper` `SignalR` `Identity` `LibMan`

### ۲. Waste_Management | سامانه جامع مدیریت پسماند شهری ♻️

[![Readme](https://img.shields.io/badge/مشاهده-پروژه-green?style=for-the-badge&logo=github)](https://github.com/abolfazlmo006/Waste_Management)

**معماری:** سه لایه (Data, WebApi) + لایه ترجمه فارسی  
**خلاصه:** سامانه‌ای تحت وب برای مدیریت غرفه‌های پسماند، پیمانکاران، شهرداری‌ها و فرآیندهای بازیافت.

#### تحلیل عمیق معماری:
- **الگوهای طراحی:** این پروژه فراتر از CRUD ساده رفته و از **الگوهای Repository و Unit of Work** برای مدیریت تراکنش‌ها و دسترسی به داده استفاده کرده است.
- **مدیریت موجودیت‌های پیچیده:**
  - **BoothEntity:** مدیریت غرفه‌های پسماند  
  - **ContractorEntity:** پیمانکاران حمل و جمع‌آوری  
  - **ExhibitorEntity:** غرفه‌داران  
  - **MunicipalityEntity:** مناطق شهرداری  
  - **WasteEntity:** ثبت انواع پسماند  
  - **User_Request_Exhibitor:** پیاده‌سازی فرآیند درخواست برای غرفه‌داری (مشابه الگوی workflow)
- **DTO و AutoMapper:** استفاده گسترده از ویومدل‌های اختصاصی برای API.
- **Persian Translation:** لایه مجزا برای ترجمه پیام‌های سیستمی.

**تکنولوژی‌های کلیدی استفاده شده:**
`ASP.NET Core 7` `EF Core` `Repository Pattern` `Unit of Work` `AutoMapper` `Swagger`
